# ImportAgentSyncMode

Whether the imported version is staged (saved without updating the live version) or published directly to the live version.


## Example Usage

```java
import com.glean.api_client.glean_api_client.models.components.ImportAgentSyncMode;

ImportAgentSyncMode value = ImportAgentSyncMode.STAGED;
```


## Values

| Name        | Value       |
| ----------- | ----------- |
| `STAGED`    | STAGED      |
| `PUBLISHED` | PUBLISHED   |
